How It Works

1. Install

Download the ZIP and extract it. Open chrome://extensions or edge://extensions and enable Developer mode.

2. Load the extension

Click Load unpacked and select the extracted folder containing manifest.json.

3. Make it yours

Visit GitHub, open VELNAR from your toolbar and choose a theme. Your choices stay on this device.

Privacy

VELNAR never collects analytics, never tracks you, and never sends data to any server. All settings are stored locally in your browser using the Chrome Storage API. No GitHub tokens, cookies, or personal data are ever accessed or stored.

FAQ

Does VELNAR change GitHub's functionality?

No — VELNAR only changes appearance. All GitHub features work exactly as before.

Is my data sent anywhere?

No. VELNAR is fully local-first, everything stays in your browser.

Can I write my own CSS?

Yes, the Custom CSS panel lets you write and validate your own styles.

Which browsers are supported?

Chrome and Edge today, with Firefox support planned.
